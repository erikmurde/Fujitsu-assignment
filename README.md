# Fujitsu-assignment
Java test assignment for Fujitsu. 
A web application that implements the delivery fee calculation sub-functionality for a food delivery application.

Use [this link](http://localhost:8080/swagger-ui/index.html#/) to access the REST API documentation after starting the application.

### Run application
```shell
./gradlew bootRun
```

### Run tests
```shell
./gradlew test
```
